description: Assess a target claim against primary literature and the stated intervention.
license: Apache-2.0
---
Match mechanism, modality, population, compartment and endpoint to the actual decision. Separate target engagement, biological effect and clinical outcome. Keep tissue expression, surface accessibility and functional dependency distinct. Trace multiple publications to trial and cohort identifiers. Record comparator, sample size, endpoint definition and follow-up. Seek counterevidence and specify which observation would change the decision.

Tools and packages: use configured literature and registry connectors through their registered tools. Preserve retrieved quotes and accession or trial identifiers. Read the primary record before assigning support.

Data license and limits: record the terms attached to each dataset or publication. The Skill license covers these instructions. Project data retain their own access and reuse conditions. Mark missing metadata as unknown.
