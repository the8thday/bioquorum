Check source identifier, salt or mixture, stereochemistry, protonation and measured entity. Retain the supplied record before normalizing. Compare quantities only if endpoint, assay conditions and units support the comparison. Preserve inequality and missing-value qualifiers. Identify duplicates and discordant entries. State what is needed to associate a structure with a particular measurement.

Tools and packages: use recorded SDF/MOL inputs and an available cheminformatics package such as RDKit for identity or depiction. Check package availability, record versions and inputs, and bind reported values to the producing run.

Data license and limits: record the terms attached to each dataset or publication. The Skill license covers these instructions. Project data retain their own access and reuse conditions. Mark missing metadata as unknown.
