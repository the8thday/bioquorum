Identify chain, deposited model and numbering convention before comparing a position across records. Preserve author chain, label chain, author residue, insertion code and sequence position independently. Distinguish missing coordinates from a deletion. State assembly, alternate conformation and method when these affect an observation. Limit conclusions about function or binding to supporting evidence.

Tools and packages: inspect FASTA and PDB/mmCIF artifacts in the local viewers. Use a recorded Python or R calculation for a geometric measurement. For a configured remote calculation, call only a registered external service through invoke with the applicable project classification.

Data license and limits: record the terms attached to each dataset or publication. The Skill license covers these instructions. Project data retain their own access and reuse conditions. Mark missing metadata as unknown.
