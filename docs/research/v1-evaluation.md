# v1.0 候选版的评测结果

这份报告汇总 OpenAI、DeepSeek、Qwen 和 Llama 的实测。除当次执行的公开 TableQA 外，其余结果来自注明版本的冻结实验。不同模型并非全部跑过相同任务，不能从这些数据排出模型总榜。

## 未参与规则调参的题目或答案

| 问题 | 观察 | 解释范围 |
|---|---|---|
| 整套 harness 对覆盖有多大影响？ | OpenAI GPT-6.1 Sol 在 30 道题上，minimal 命中 18/80 个冻结覆盖项，current 命中 71/80；组学题两组都是 17/20。 | 按同题配对；工具配置和提示均有改变。每组的用量和逐项结果见 [v0.8 基线](v08-baseline.md)。 |
| 对给定数据，得到的答案是否正确且有据？ | DeepSeek V4 Pro 四道留出题，基线答对 17/17 项，有据且答对 0/17。完整默认组答对 11/17，有据且答对 6/17；加一轮退回两项分别为 17/17 和 12/17。 | 准确率与可追溯性各用各的分母。[真实数据对照](harness-research-eval.md) |
| 本地开放权重模型遵从绑定语法吗？ | 在绑定提示组的留出回答中，Qwen3 4B Instruct 的有据结论为 0/17，Llama 3.2 3B 为 0/24。DeepSeek 的相应实验为 11/15。 | 分母是各组抽取的结论条数。可以答中事实却未绑定输出。表内的分数不能外推到其它模型大小。[绑定实验](binding-eval.md) |
| 审查能检出多少注入错误？ | 对未参与调参的 DeepSeek Flash 和 GPT-5.4-mini 答案，确定性规则共检出 58/62 个已注入错误；370 条结论中记录 1 条误报。 | 留出集只注入三类机械可核对错误。方法选择与文献对结论的语义支持另行审查。[审查实验](review-checks.md) |
| 能从未用于本项目调参的论文表图作答吗？ | 本轮 GPT-6.2 Sol 在 32 道独立来源的单表题中命中 28 道（87.5%）。全部取得答案，4 道错题保留。 | 公开题的预训练暴露未知。评分使用固定选项全文，模型实际经历图片大小限制、取图工具和预算。[正式协议与结果](v1-tableqa.md) |

## 开发集与已看过的结果

PlantGrowth 开发题上，DeepSeek V4 Pro 的基线与完整默认组均答对 3/3 项，后者有据且答对 1/3 项。手写审查语料检出 21/24 个注入错误。参与调整规则的 GPT-6.1 Sol 原答检出 29/31；这些数不能替代留出集。模型在靶点、组学、证据综述的推荐配置选择和确认运行使用了不同子集。[开发题](harness-research-eval.md) · [看过与未看过的答案](review-checks.md) · [配置选择和确认](v08-profile.md)

## 独立重复的假不一致

两项有已知计数、保留实测记录的盲重复是合成细胞总数（68）与 GSE96583 配对供者数（8）。两次有效比较都匹配；在这两个可判定案例中观察到 0/2 次假不一致。另有一次早期运行因内核导入失败而未能判定，单列保留。两道整数计数题不足以估计复杂科学分析中的假不一致率。跨系统 CSV 字节校验另属同代码重跑。[计数表](../release/v0.4-acceptance.md) · [R 盲重复](v09-r-kernel.md) · [跨系统重跑](../release/v1.0-acceptance.md)

## 同模型两天对照

第一天六题，BioQuorum 命中 12/16 项，通用 Codex 命中 7/16 项；累计用时分别为 1,038.3 秒和 476.9 秒。第二天，同一接手者先后用两个系统修订上游材料，两组均为 5/5，分别用时 18 分 50 秒和 4 分 53 秒。接手者只有一人，先后次序固定，无法把学习效应与工具差异分开。通用 Agent 没有可核实的美元账单。[第一天](v08-day1-comparison.md) · [第二天](v10-day2-comparison.md)
