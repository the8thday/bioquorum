# v0.2 真实研究数据上的 harness 对照

2026-11-19。用同一模型在同一研究题上比较仅提供 kernel 的基线、当前完整工作流，以及允许一轮自动退回的完整工作流。选用公开发表的经典实验数据，题目是为这次评测新写的。这里的留出指这些题未参与规则、提示词和打分的调整。原始数据广为公开，无法断定模型训练时未见过。

## 数据和评分

- 开发题是 PlantGrowth 的均值对照。留出题包括 ToothGrowth 的剂量内差值、CO2 的植物内配对变化、ChickWeight 的完整配对增重、sleep 的患者内变化。R 4.6.0 导出原始数据。独立的 R 答案先于模型运行生成，Python kernel 中只装入 CSV 和官方文档的一段摘录。题目、答案规则和各数据文件用 SHA-256 固定。 [PlantGrowth](https://stat.ethz.ch/R-manual/R-devel/library/datasets/html/PlantGrowth.html) [ToothGrowth](https://stat.ethz.ch/R-manual/R-devel/library/datasets/html/ToothGrowth.html) [CO2](https://stat.ethz.ch/R-manual/R-devel/library/datasets/help/CO2.html) [ChickWeight](https://stat.ethz.ch/R-manual/R-devel/library/datasets/html/ChickWeight.html) [sleep](https://stat.ethz.ch/R-manual/R-devel/library/datasets/html/sleep.html)
- 三组共享题目、只读输入和隔离的 Jupyter kernel。基线只有最短系统提示和 `python_execute`，可以从 kernel 读取研究摘录。完整组使用生产提示、来源编号、证据解析和审查，并可通过 `read_file` 引用同一摘录。生产默认组不开退回，附加对照允许一轮。工具集和提示词同时改变，因此基线对照测的是整套工作流。
- Rubric 分两列。答对要求给出指定精度的数值或正确的研究设计。答对且有据还要求数值绑定到成功运行的命名记录，或设计结论绑定到正确摘录。补充记录产品审查流程抽取的有据结论数，分母为抽取条数。报告按题单独保存评分和输出。
- 两套模型的审查器固定为 DeepSeek Flash。给基线运行的结论抽取属于测量开销。对比 worker 耗时和用量时单列这部分。成本用 DeepSeek 高峰费率估算。 [价格表](https://api-docs.deepseek.com/quick_start/pricing/)

## 运行中发现的接口问题

首次运行使用原有 DeepSeek Chat Completions 路由。在停止前写出的 19 个结果里，Flash 有 8 个臂在回传工具结果时遇到 API 400。事件表显示至少一份模型响应含工具调用却没有返回推理字段。通用配置会省略缺失字段，DeepSeek 的工具回传要求该字段存在。模型层改用 Pydantic AI 的 DeepSeek 专用 Chat 配置，测试检查已有推理原样回传，缺失时随工具调用发送空字段。配置生效后，从全新会话重跑全部对照组，旧批次保留作故障记录。 [DeepSeek Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)

人工复核给 Flash 的 CO2 基线补回 4 项，原答复以逗号分隔标签和值。Flash 的一轮退回组中，CO2 的两段结果重复且一致，补回 4 项，ToothGrowth 的剂量标签带括号，补回 3 个正确差值。V4 Pro 完整默认的 ChickWeight 正确计算了未舍入的数，但默认显示用四位有效数字，两个均值显示为 136.2 和 197.7，未达到题目要求的两位小数。这两项在人工评分中也保持扣分。

修复 DeepSeek 请求后，正式评测的 132 条运行启动事件均记录了无网络的 bubblewrap，30 个组合中没有再遇到 `reasoning_content` 400。另有一个超时和两个连接错误。三个单独复跑均答对原题的四项，保留在独立结果中。以复跑替换传输失败作敏感性分析，V4 Pro 的完整默认达到 **15/17** 答对、**10/17** 答对且有据，基线为 **17/17**、**0/17**。Flash 的基线和完整默认均达到人工答对 **17/17**，自动有据为 **0/17** 和 **5/17**。这一批最稳定的收益是结论可追溯性。有限样本和单次运行不足以确认准确率提升。

## 退回复核

正式试验中，允许一轮退回的 10 个组合触发 1 次，来自 Flash 的 PlantGrowth 开发题。它修好了摘要中未声明的变量，保留了原有三个正确答案和正确的引文绑定，增加 **4 次** worker 调用。由于重新作答仍在数值结论中混用了裸数字，严格 rubric 的有据项仍为 **1/3**，原始通过的数值标记则从 0 增至 6。8 个留出题组合没有触发退回，两个完整组之间的分数差不能归因于退回功能。继续保留默认 `binding_retries = 0`。 [冻结错误输入的修复实验](binding-repair-eval.md)

主评测已返回用量的费用估算约 **0.284 美元**。加上停止前的故障批次和三次复跑约 **0.439 美元**，按高峰费率估算。真实账单未核对。
