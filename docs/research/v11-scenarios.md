## 科学结论与证据

Cho 等人在原论文摘要中将结合位置描述为 HER2 的近膜区域。1N8Z 是人 HER2 胞外区和曲妥珠单抗 Fab 复合物的 X 射线晶体结构，分辨率 2.52 Å。本例采用已提交的模型 1，A 链为 Fab 轻链，B 链为 Fab 重链，C 链为 HER2。[结构条目和作者摘要](https://www.rcsb.org/structure/1N8Z) · [原论文](https://doi.org/10.1038/nature01392)

对任意一个 Fab 残基和一个 HER2 残基，取两者所有已建模蛋白重原子之间的最短距离。阈值由示例设为 ≤4.0 Å。排除氢、氘、非蛋白分子、零占有率坐标；替代构象取无标识或 A。同一残基对只计一次，在舍入前判定阈值。该定义得到 **14 个 Fab 残基、17 个 HER2 残基、32 对跨界面残基**。其中 Fab 轻链 8 个，重链 6 个。文件表头区分 FASTA 位置与作者编号；下表用结构文件的作者链号和编号。[分析代码](../../examples/v11/interface.py)

| 可在工作台复查的内容 | 结果 |
|---|---|
| HER2 接触位点，C 链作者编号 | 557、558、560、561、569、570、571、572、573、591、593、596、598、600、602、603、604 |
| 一个可以逐项核对的接触 | A 链 Asn30 与 C 链 Asp596 的最近重原子距离约 2.99 Å |
| 从序列核对结构 | 在轻链 FASTA 注释点选 Asn30，再在 Mol* 选择 C 链 Asp596；两者可分别附入同一追问 |
| 从研究线核对结果 | 数值引用指向实际 kernel run；论文引用可展开查看摘要原句、PMID 和材料来源 |

这些接触描述这一晶体模型中的几何邻近关系。阈值变化会改变名单，结构中没有坐标的残基无法参与计算。判断某个残基对亲和力或生物活性的贡献，需要突变、结合或功能实验。这里的编号专指 1N8Z；对照其他蛋白序列或抗体编号系统时需另做映射。
