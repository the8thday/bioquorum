# v0.3 计划门槛对照

计划开关按会话轮次启用，默认关闭。可观察的目标是用户批准前不调用 worker 或工具，
以及记录已批准的偏离。比较使用相同的场景 C 摘录、同一记录引擎和不同的回放路径。

| 配置 | 批准前模型 / 工具调用 | 审批后的步骤记录 | 结果 |
| --- | ---: | ---: | --- |
| 直接运行 | 无审批点 | 无 | 回放生成结论和证据 |
| 提交后等待批准 | 0 / 0 | 2 | 批准后回放生成相同结论和证据 |
| 拒绝计划 | 0 / 0 | 0 | 保留拒绝记录 |

开发用例是离线二甲双胍回放。单独的控制测试覆盖打断后更换研究方向、挂起权限时
的事件闭合、流程中断恢复、父会话继续写入后的固定分叉，以及计划偏离的批准和拒绝。
测试衡量控制流程，这一轮没有用新付费模型测规划对科学答案正确率的提升。
计划作为用户可选控制保留，依赖服务端硬性批准门槛和可重放事件来检验效果。

复核命令：`uv run pytest tests/unit/application`。
