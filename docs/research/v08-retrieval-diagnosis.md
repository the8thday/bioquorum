# 四道靶点评估的漏项诊断

2026-11-21 复查本机 v0.5 的四个自主检索项目。每题逐一对照事件库中的工具参数、工具返回、对应回答和原题评分项。以下 s1 等别名仅在该行所指题目内有效。此次直接读到的是本地 Qwen 的记录。OpenAI 历史复测有独立的[既有报告](v05-target-expansion.md)，其服务器端的原始会话没有随代码同步，两次运行不能混作同一因果链。

| 问题和未覆盖的证据 | 直接观察 | 漏在哪一步 |
|---|---|---|
| TYK2，保护性遗传变体及感染边界 | 两次 GWAS 都用 rs11085726，s1 和 s4 均为空。综合文献检索超时；没有发起针对感染风险的查询。回答将空结果推广为整个靶点缺乏遗传证据。 | 变体查询未命中；感染证据未单独检索；另有越界的否定性陈述。 |
| TYK2，JH2 机制、选择性与获批范围 | 成功请求只有 GWAS、试验注册和 HPA；试验标题提到药名，未调用标签或摘要工具核实机制。 | 决定机制结论所需的来源未检索。 |
| PCSK9，人群遗传和双等位缺失 | s1 给了五条标题；实际阅读的 s3 是 PMID 42932357 的肝细胞模型。没有取回人群遗传研究。 | 宽泛检索未命中所需证据类别，已读材料不能支持人群结论。 |
| PCSK9，获批治疗和心血管结局 | 标签参数为类别名 PCSK9 inhibitor，返回 404。s2 列出试验注册标题；没有取回结局试验论文。 | 标签检索失败；已发表的结局研究未针对性检索。 |
| HSD17B13，保护变体和组织学表型 | 两次 rs7243652 查询均为空。s1 命中含保护性变体的 PMID 42650052 标题，读取该摘要超时。 | 变体查询未命中；相关标题命中，正文证据没有成功读到。 |
| HSD17B13，细胞定位、保护机制与管线 | 未调用表达工具。注册查询混入多项无关试验，含 AZD7503 标题但无足够机制或疗效信息。 | 表达证据未检索；试验列表未支持进一步机制判断。 |
| NOD2，三种风险变体、功能方向、表型 | 广义检索 s1 后读取三篇摘要，其中有一篇幼年特发性关节炎家系论文。两次试验查询均为空。没有取到变体功能原始研究。 | 检索未命中所需的功能和表型证据；成功读到摘要不等于支持这些结论。 |

这批记录首先支持检查“用什么查、返回了什么、摘要是否真的取到”。它们不足以断言 OpenAI 复测中的每个漏项也发生在检索环节。要认定“读了却没写”，需要在那次运行的成功返回中指出包含该证据的原句，再对照最终回答。OpenAI 的 JH2 选择性、PCSK9 结局和 NOD2 变体仍应按此标准复核。

后续覆盖台账应区分成功空返回、请求失败、仅命中标题和已取到原文。结果数无法可靠解析时保留未知。技能可提示研究者检查人群与细胞模型、试验登记与试验结果、检索标题与实际读取材料的区别。这些做法可以跨题验证。
