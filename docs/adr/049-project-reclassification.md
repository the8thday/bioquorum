# ADR-049 · 更改已有项目的数据分级

接受。研究者可在项目设置中明确选择并保存新的数据分级。保存前显示对整个项目已有会话和文件的影响；修改只在项目空闲时提交。项目沿用原标识，后续模型路由、工具调用和内核按新分级执行，历史事件和材料版本保留原记录。

初始分级来自创建事件，后续分级来自带版本检查的 ProjectSettingsChanged 事件。项目列表投影和重新打开工作区均采用最近一次修改。修改 TOML 中的 project.classification 不能改变有效权限。变更分级本身不会打开数据库开关或授予工具权限。

公共数据库在没有显式开关时的行为已由 [ADR-050](050-public-research-default.md) 更新。
