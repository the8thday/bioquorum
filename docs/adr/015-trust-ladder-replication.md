# ADR-015 可信度阶梯与独立重复

状态：已接受（2026-11-17）。`grounded` 实现于 v0.2，`reproduced` / `replicated` 实现于 v0.4。扩展 ARCHITECTURE §5.7。

## 背景
v0.1 的状态机是 `unverified → reviewed → reproduced`，另有 `disputed`。对照实验（docs/research/reviewer-experiment.md）说明模型审查的增量来自 reviewer 的能力，换一家模型并不多抓错；可靠的是能机械核对的证据。"共识模式"原先排在 v0.6 以后，但它才是名字里 Quorum 的含义，也是科学界本来的最高标准：独立重复。

## 决定
【承重】验证状态扩展为五级加一个争议态：

```
unverified → grounded → reviewed → reproduced → replicated
（任一级出现不一致或 error 级 finding → disputed）
```

| 级别 | 含义 | 怎么得到 |
|---|---|---|
| `unverified` | 仅为断言 | 默认 |
| `grounded` | 数字和引用都绑定到了证据 | ADR-014 的确定性解析 |
| `reviewed` | 没有未解决的 error 级 finding | 确定性检查 + 模型判断检查 |
| `reproduced` | 同一份代码、环境、输入重跑，结果一致 | `run_key` 比对（§5.6） |
| `replicated` | 另一次独立分析得到同样的量 | 见下 |

- **独立重复**：新开一个会话，全新上下文。它拿到问题、输入数据、要计算的量的**名字、定义和单位**，拿不到原来的数值、代码和回答。它自己完成分析并用 `bq.value` 给出同名的量，按容差比较；容差和比较结果写进事件。
- 重复者默认用 worker 模型，可配置为别的模型。在测出差异之前，不宣传"换模型重复更可靠"（沿用 ADR-013 的态度）。
- 级别不能跳：重跑一致不能替代有据和审查。
- 不适用的级别如实显示：文献类结论没有"复现"，最高到 `reviewed`。
- 状态仍然只通过 `claim_status_changed` / `artifact_status_changed` 事件改变，一个回答的整体状态取最低的结论。
- 取代 §10 里的"共识模式"。

## 后果
- `core/status.py` 的枚举和转移表在各级实现时扩展，转移表保持"每个（状态, 触发）都有定义"。
- 独立重复花钱花时间：由用户按结论或按整份记录触发，触发前显示预估费用，不默认执行。
- 两次独立分析因合理的方法差异而不一致，本身是有价值的信息：界面并排显示两边的方法和数值，由人判断，不自动裁决。
- 评测要报告假不一致率（两边都对但被判不一致）。
