# ADR-022 重跑、盲重复与研究包

状态：已接受。补充 ADR-010、015、017。

重跑在新的工作目录和 kernel 中用原始代码和 CAS 输入进行。运行保存输入相对位置，
以及实际 kernel 的环境指纹；启用 pixi 时同时保存锁文件摘要。重跑比较运行身份、
命名值、文本和输出对象。无法重建或运行失败属于未能判定。只有审查过的结论才有
资格升级，多个计算依赖必须分别通过。无锁或未隔离的匹配只显示为本机核对。只有匹配 pixi 锁及实际内核指纹、全程无网络隔离的计算才可升级。

独立重复在无父历史的会话中运行。计划仅附用户确认的中性问题、输入、量名、定义、
单位和预登记容差。代码和原值不发送给模型。隔离不可用时拒绝运行。结果比较只在模型
完成后执行；容差、预算估计及比较结果随事件留档。人工主动启动，默认不调用。

研究包 v1 保留 v0 字段，增加声明输入的相对路径、构建环境、绑定关系和可独立运行的
入口。默认按选定会话导出显式的代码、数据和证据，省略服务商私有推理和工具调试信息。
研究包是含数据、代码的主动导出物。检查文件哈希后，接收者显式运行。
