# ADR-041 研究线更正、重算与接手

状态：已接受（2026-11-21）。落实 ADR-014、015、018、031、032、039、040。

## 背景

上游更正可能同时影响两个语言的计算、研究结论和据此做出的决定。研究者需要先了解影响范围和成本，才能决定是否动用计算资源，并能向接手者解释新旧记录之间的关系。

## 决定

- 从登记的材料、运行输入哈希、已记录的文件交接、值与图的引用、固定版本的决定和导出清单推导下游。常驻 kernel 的先前状态可能影响后续单元，因此影响范围可以包含同一 kernel 的后续运行。
- 用追加事件标记复核状态。研究者启动后，在新会话和隔离内核中用更正的输入执行原代码。新测量按绑定规则取得等级。原来的判断、决定和历史包保留其版本。失败时保留错误与原始运行，后续代码修改需要新的执行记录。
- 接手摘要与研究线包包含返回原始事件的标识。跨会话阅读是默认关闭的可选工具，只允许读取本会话所属研究线。它返回的值、结论与决定只作背景，后续证据仍要回到原始来源或运行。
- 第二天对照复用两组真实第一天记录，冻结更正、任务和评分办法，再由未参加原研究的人接手。自动化演练和模型评测各自单列。

## 后果

模型不能仅凭接手摘要给结论升级。研究者可以独立复核材料更正、当前决定与原始证据。跨会话读取的配对实测见[上下文评测](../research/v10-program-context.md)。
