# ADR-023 项目 Skills 与跨会话笔记

状态：已接受。补充 ADR-002、006、007、018。

项目主动打开 `[agent] skills` 后，发现 `.bioquorum/skills` 中的 Agent Skills。
首轮只给模型名称和描述，模型明确调用工具才读正文与文本引用。激活内容和 SHA-256
保存在工具事件中。目录隔离、资源体积及工具权限照常生效，Skill 不能授予权限。
基础格式按 [Agent Skills 规范](https://agentskills.io/specification)；不自动下载或执行脚本。

`[agent] project_notes` 提供跨会话的项目笔记。作者保存的版本进项目事件流，模型可
按需读取、提交草稿。草稿只存在于提出它的会话，作者接受后才生效。保存要携带所编辑
的版本，避免多个窗口互相覆盖。两项机制独立，默认关闭。说明、笔记和草稿是研究背景，
不进入引文或数值证据，也不进入导出的研究包。盲算环境不继承这两个开关。
