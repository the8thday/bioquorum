# ADR-011 reviewer 默认与 worker 不同模型家族

状态：**已被 [ADR-013](013-reviewer-by-capability.md) 取代**（2026-11-17）。原状态：已接受（2026-11-13）

## 背景
产品的核心差异点。同模型自审会复制自身的系统性偏差。这是一个待验证假设，v0.0 的对照实验将给出数据。

## 决定
配置中 reviewer 与 worker 同家族时启动给出警告，需显式 `allow_same_family = true`。确定性检查不依赖模型；跨家族价值只体现在模型判断类检查和共识模式，评测报告必须分开报告两组指标。

## 后果
- 用户至少要配两家 provider（本地模型算一家）。
- 若对照实验显示跨家族无显著优势，本 ADR 需被新 ADR 取代，产品定位同步修改。
