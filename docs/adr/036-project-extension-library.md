# ADR-036 · 项目扩展管理

已接受。工作台在侧栏和设置中提供 Skills 与 MCP connectors 管理。显示偏好仍属于本机，扩展属于当前项目。用户安装的 Skill 作为不可变文本包保存在项目状态目录，设置事件记录启用的版本；旧的手工安装目录继续由原加载器读取。运行中的研究保持原目录和工具快照。移除只撤销项目注册，既有研究记录和作者维护的文件继续可读。

连接器可注册 HTTPS 服务，或注册机器上已有的隔离 stdio 程序。配置操作不执行命令、不安装依赖。发现工具和研究调用继续经过已有连接器、权限与审计入口；目录中区分已添加和实测可达。研究设置沿用版本检查和事件回放，CLI 和浏览器使用同一套有效扩展。

工作台列出随包提供的 Skill，按项目启用时沿用文本导入、版本和权限机制。公共数据库工具在 MCP 设置旁单独显示，项目可直接调整现有的 `connectors.public_sources` 开关。工作台新建 Public 项目时默认提供这些工具，优先尊重用户已有全局配置。实际外发查询仍逐次经过分级与权限检查。
