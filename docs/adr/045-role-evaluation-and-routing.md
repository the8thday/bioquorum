# ADR-045 · 根据可复核的逐角色成绩建议模型

## 背景

项目可为研究、审查、计划和上下文压缩指定不同的模型。备用模型的实际使用、比较题的失败与适用的数据分级都会影响研究者如何选模型。

## 决定

- 每个角色先按项目数据分级过滤候选模型，再按指定顺序尝试。切换时写入 `model_route_fallback`，关联失败调用与下一次尝试。工作台回答展示完成该回答的模型。
- `bq models eval` 只评测当前项目允许的模型。每个候选固定为同一模型，按四个角色各回答两道固定题。比较题的文本、评分代码与协议版本可查。项目事件按模型保存各角色的计数、失败和回复。
- 设置页显示最近一次逐模型成绩。每个角色按当前允许且该角色两题都取得回复的候选计算建议，显示非零最高分的所有并列者。修改角色默认与备用链需要研究者显式保存。
- 计划草稿由 planner 生成并写入 `plan_drafted`。研究者可以修改步骤，执行仍走现有的计划批准流程。上下文压缩继续使用 summarizer。

## 后果

设置建议能追溯到题目和模型。每角色两题只适合初步筛查，不能据此判断复杂研究质量。运行评测时使用项目配置的 provider；这项操作由用户从 CLI 发起。
