# ADR-021 本地工作台、计划和会话分叉

状态：已接受（2026-11-19）。补充 ADR-016、018。前端"原生模块、无构建链"的部分自 v0.7 起被 [ADR-029](029-built-frontend.md) 取代，其余继续有效。

CLI 和 Web 共用 application 层的组装、执行和控制入口。FastAPI 仅在 server，
Web 客户端使用随包发布的原生模块和 CSS。界面只需要有限的交互组件，第一版无需
JavaScript 构建链和客户端依赖。服务绑定于 IPv4 loopback，拒绝不匹配的 Host 和
非同源写入。服务端根据项目内已有的记录授权读取图；预览限于图像，SVG 采用隔离策略。

一次交互由 turn_requested、turn_started 和 turn_finished 标识。计划可独立启用，
包含人可以编辑的步骤。在批准前无 worker 或工具调用。完成步骤和偏离原因通过
invoke 记录；偏离需要先请求一次性权限。计划门槛与审查状态各自独立。
打断取消当前任务，已完成的事件保留，历史中每个工具调用闭合；下一次交互使用新 kernel。

分叉以父会话的固定日志位置为界，仅记录父会话和位置。事件读取展开祖先前缀，
不复制原事件和 CAS 对象，不继承内存 kernel、待批准的操作或临时权限。
每次交互共享当前项目的文件系统，分叉不是文件快照。SSE 以会话内 seq 恢复，
模型流式进度为瞬时帧。进程退出后未完成的任务不会自动重试。

功能对照见 docs/research/v03-plan-gate.md；计划默认关闭。
