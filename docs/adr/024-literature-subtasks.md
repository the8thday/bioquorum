# ADR-024 有限的文献检索子任务

状态：已接受。补充 ADR-006、007、014、018。

`[agent] literature_subtasks` 独立开启。仅允许作者在
`literature_tools` 显式列出的只读文献连接器工具。子任务复用 worker 模型和现有
分类权限，从空白上下文开始，只得到交办问题。一般提问保留直接检索。显式 `/literature` 在主模型开始前自动执行一次子任务；
没有模型自动选择的依赖。可用权限是父会话已有授权，
无授权时拒绝。子任务没有 kernel、项目笔记、Skills 或继续委派的入口。

每轮至多委派一次。子任务有工具、模型轮次和时间上限，实际观测的模型使用量
计入主轮预算。开始、结束、估算使用量和来源引用写入父会话；完整内容写入同一
数据库的独立事件流，不进入父对话。只有工具原文中的短摘录可以成为可点击证据。
摘要对父模型仍是不可信提示，只能用来定位来源。主工作台可由证据抽屉回溯子任务
实际工具结果。停机与中断留痕。
