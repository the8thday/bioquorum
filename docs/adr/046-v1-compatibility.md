# ADR-046 · v1.x 的兼容边界

已接受。落实 1.0.2，补充 ADR-010、020、022、023、042。

v1.x 读取 v0.6 至 v0.12 留存的项目。数据库迁移使用既有 Alembic 事务，事件在读取时逐版升级，持久的原事件保留原貌。遇到本程序尚不认识的事件版本，解析应明确失败。发布测试使用对应历史提交实际生成的项目以及当前的重建和追加写入入口。

研究包 v1 按随仓 JSON Schema 解释并沿用原有哈希与重算判定。受支持的 TOML 字段及其既有含义、默认权限、项目 Skill 目录、通过 MCP 接入 Connector、Check 协议、随包构建的 ViewerProps 和元素引用遵循[兼容规范](../compatibility.md)。增量功能可添加可选字段；不兼容的持久格式须另立版本并提供迁移或并行读取。查看器由开发者编译进发行包。当前未实现 Python entry point 自动发现，现有工程不应依赖该入口。
