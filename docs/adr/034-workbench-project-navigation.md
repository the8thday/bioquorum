# ADR-034 · 工作台的项目导航和研究面板

接受。作者在 0.7 观感验收中指出项目入口缺失、会话工具挤占正文、用量数据在窄栏断开。

左栏同时提供新建项目与项目切换。工作台创建的项目放在用户目录的 .bioquorum/projects 下，各自用现有初始化、分级、事件库和项目锁。目录名由程序产生，页面提交项目名与分级。命令行指定的启动项目保留在切换列表。目录扫描只读本机已初始化项目的元数据。项目之间不复制研究记录、模型密钥或权限。

记录以问答顺序阅读，会话管理放入操作菜单。辅助面板按需查看，用量以总量、角色与预算分层呈现。判断证据强度的原规则继续适用。

2026-11-22，侧栏增加项目级 Research tools 入口。目录复用项目设置快照及现有工作台导航。打开目录只读当前设置；研究操作继续使用原始记录和审批流程。[版本与入口](../workbench-capabilities.md)
