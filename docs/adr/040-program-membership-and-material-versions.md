# ADR-040 研究线归属与材料版本的身份

状态：已接受（2026-11-21）。落实 ADR-031 的前两步。

## 背景

一个项目可以同时研究多个问题，多个会话也可能上传同名文件。研究者需要明确一个会话归属哪个问题、一次更正针对哪个版本，并能在更正后取回原件。

## 决定

- 一个会话可以独立存在，也可以归入同项目的一条研究线。关闭研究线后可以继续读取研究记录。更改研究线或材料均由研究者经工具入口发起，写入项目级事件流。
- 当前结论列出已加入会话自身产生的结论，按每个回答最近完成的审查选取，并显示结论后续达到的等级。分叉会话可沿用祖先记录解析证据；同一条祖先结论在研究线上只列一次。
- 研究者可以登记本项目已有的上传。材料版本引用原始上传事件，沿用当时记录的内容哈希、文件名和分级。每次更正指明被取代的具体版本，并记录新来源和更正原因。
- 一条研究线内，同一笔上传只登记一次。两个不同文件即使同名也可以分别登记。两个同时提交的更正若指向同一旧版，只能有一个成为有效的新版本。
- 撤回保留历史字节与版本说明。登记人沿用现有单用户工作台的研究者角色，登记时间取自事件。

## 后果

研究者按版本下载时能核验原始内容。项目已有的事件日志和文件库足以支撑这两步，可以与 v0.9 并行实现。识别受更正影响的下游结果与启动重算分别由 0.10.3 和 0.10.4 交付。
