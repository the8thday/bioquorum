# ADR-037 · 在对话旁打开研究结果

接受。研究者从对话里的结果或 Artifacts 打开右侧阅读区。两者使用会话内同一产物版本 ID 及已记录的内容哈希。选中的结果、栏宽和展开状态属于界面布局。两个栏位可独立调整，结果阅读区与对话可同时操作。窄屏优先给当前查看的结果分配空间，并提供返回对话的入口。

## 交互参考与取舍

| 观察 | BioQuorum 的交互 |
|---|---|
| 作者截图中左侧保留分析对话和追问框，右侧有文件标签和报告正文 | 点击记录中的图、表或报告时在右侧打开；草稿留在原会话。 |
| 截图中导航可以让出空间，报告中的图表占据更宽区域 | 导航可收成图标栏。两条分隔线支持拖动，也支持键盘方向键。 |
| 截图中同一份报告包含标题、表格和图 | Markdown 报告支持标题、表格及同次运行中已记录的相对路径图片；保留下载原文件的入口。 |
| Anthropic 的公开说明描述了在对话旁打开独立产物并继续迭代 | 支持在已打开的结果间切换，按版本查看，逐个关闭。证据等级继续来自原研究记录。 |
