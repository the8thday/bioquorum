# ADR-039 · 两种语言的执行、交接与重跑

2026-11-21。落实 ADR-009、014、017、022 和路线图 v0.9。

同一会话的 Python 和 R 使用独立的常驻内核，共用项目文件。R 的解释器、IRkernel 描述和包来自作者配置的项目 pixi 环境。隔离策略沿用项目设置。R 中断和超时通过终止并重新启动该 R 内核处理，重新分配内核 ID。重建历史只恢复同一次内核生命周期中的状态。

生产者在工具参数 `output_files` 声明要交给后续单元的文件。BioQuorum 在宿主端检查文件是否写入并保存字节与哈希。消费者以 `input_files` 声明输入；输入的字节、路径和哈希进入运行记录。文件交接通过时间顺序、路径和内容哈希连接。重跑从外部输入开始，按事件顺序重建各自的内核，逐次核对中间文件。无法重建依赖时，可信度保持原级别。

R 命名值与 Python 使用同一 MIME 和宿主验证规则。同一回答内，不同语言声明同名值会导致该名字无法绑定。旧 Python 记录继续支持同语言更新命名值。计算类工具的输出不能用作文献引文。

可移植包保留 v1 结构，增加可选的内核分组、当前单元输入及写出文件哈希。旧包沿用原有的 Python 单元顺序和输入。混合会话导出 notebook 时，一个 ZIP 提供两份独立的 notebook。

补充 ADR-008 的运行身份规则。Python 继续使用原哈希输入；R 在同一材料前加上语言标记和换行再哈希。这样，同一份锁和输入上，两种语言中都合法的同一段代码有不同的运行身份。
