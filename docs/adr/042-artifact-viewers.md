# ADR-042 · 文件查看器随工作台发布，按需加载

已接受。落实 ADR-029，沿用 ADR-016、023、037 的工作台、Skill 与结果阅读约定。

## 背景

0.10 在另一工作区实现研究线。作者同意提前开展 0.11 的会话级查看器与领域工具。用户可以先在文件中探索，选定与研究相关的元素后再追问。

## 决定

- 将查看器编译为本地静态模块，由产物类型决定加载项。普通用户随 wheel 获取完整离线界面；开发者通过锁文件升级渲染库。未知类型保留原文件下载。
- 使用 Mol* 查看 PDB/mmCIF 的第一个坐标模型。选区记录模型号、作者和标准链号、作者残基编号及插入码，能取得标准序号时一并保存。选区代表用户指向的位置，几何量需要另行计算。
- 元素引用写入现有轮次事件，固定产物 ID，关联内容哈希与生成运行。表格引用使用原始数据行和列序号，序列使用 FASTA 记录号及从 1 开始的闭区间。BED 保留从 0 开始的半开区间。重开引用仍回到原版本。
- 图的点位和序列注释使用同次运行登记的伴随 TSV，按完整路径配对。缺少映射时仍可读取原文件；存在相互冲突的映射时报告错误。
- RDKit 的 Emscripten 绑定需要动态生成函数。将其限制在专用化学绘图 Worker，主界面保持脚本执行限制。Worker 仅接收本地发行的 WebAssembly 字节与所选记录，不能发起网络连接。输出 SVG 作为图片呈现。
- igv.js 使用当前 BED 的坐标范围作为显示边界。界面明确标出参考组装未知，既不推断物种，也不读取外部参考序列。第三方许可随构建产物分发。

## 后果

更换渲染库时需重跑文件读取、选择、跨轮追问、原版本回放和浏览器测试。打开多个结构模型、生物学组装以及基因组参考序列的交互可另行扩展。抗体研究线示例等待 0.10 的接口。
