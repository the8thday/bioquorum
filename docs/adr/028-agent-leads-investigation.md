# ADR-028 Agent 先调查并给出判断，人在分歧和投入上决定

状态：已接受（2026-11-20）。修订 DESIGN.md 判断⑤；补充 ADR-018、021。讨论原文见 [2026-11-20 设计讨论](../discussions/2026-11-20-agent-first.md)。

## 背景
判断⑤原文是"问什么问题、用什么方法、结论算不算成立，是人的决定"，对应的机制是"多步分析先交计划，批准后执行"。作者和 AI 的讨论得到另一个结论：研究者常常只带来一个模糊的念头，看过第一轮调查后才知道自己在意什么；每一步都等人批准，既浪费 Agent 的能力，也不给结论增加证据。计划审批在代码里已经默认关闭（ADR-021）。

## 决定
- 默认流程：Agent 收到问题后先做能独立完成的调查，给出有依据的判断，并把**最值得讨论的分歧**和**下一步最有价值的检索或实验**写进记录。只有一句话就能改变调查方向的歧义，才在开始前问，最多问一次。
- 人的决定集中在三处：这项研究服务于什么决定（可以在看过第一轮结果之后再说）；会改变结论的科学分歧；资源投入和对外承诺。花钱、联网、写项目外文件等操作的权限卡片照旧（ADR-006），与本条无关。
- 计划审批保留为可选开关，不作为默认流程。研究者可以规定方法，也可以交给 Agent 选；Agent 做的分析选择照旧写进记录。
- 【承重】人的批准不提升结论的可信度等级。等级只由 ADR-015 的机制得到。
- "把一个抗体序列推到 PCC"是作者的个人目标和项目的宣传语，用作长期的试金石；它不限定产品范围。产品服务于生物医药研发的各类研究工作。

## 后果
- DESIGN.md 判断⑤改写；PRODUCT.md 的场景描述相应调整。
- 界面需要一个固定位置显示"待讨论的分歧"和"建议的下一步"（ROADMAP v0.8）。
- 这是 agent 层机制，按 ADR-018 带开关合入，并测量它对回答质量和用量的影响。
