# ADR-047 · 项目设置与工作台回收站

接受。研究者可以在创建项目时填写说明，在项目设置中改名、修改或清空说明。复用带版本检查的 ProjectSettingsChanged；显示名称由项目投影给出，项目标识和链接稳定。用户填写的说明随该项目后续研究回合与计划草案生效，空文本即关闭。说明是研究者偏好，证据规则、分级和工具授权仍由各自机制执行。

首页分别报告当前分级允许的 worker 和工作台进程中的凭据状态。本地检查只读取配置和变量存在性。首个模型可以在图形界面明确选择，使用预定义提供商及环境变量引用，保留用户已有的分级和提供商限制。

删除工作台管理的项目时，按目录标识确认并将整个项目原子移入本机回收站。恢复沿用原标识。命令行启动的工作目录不属于工作台可移动的目录。移动之前检查项目锁、正在执行的请求与研究操作，关闭相关子应用。工作台回收站的文件夹位置决定项目是否出现在活动列表。
