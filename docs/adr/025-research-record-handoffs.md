# ADR-025 证据、计算输入和模型图片的交接

状态：已接受。补充 ADR-007、014、018 与 022。

研究包支持只含检索证据的会话。沿用 manifest v1 和文件哈希，计算清单可为空。两类包都从已归档的来源和 run 生成 `Methods.md`，用已记录的路径、参数、版本与输入哈希起草。纯文献包可以离线校验文件；有 run 的包还能运行原有重跑入口。

语义审查接收逐字核对后解析出的引用和同一来源的附近上下文。审查模型缺少某条结论的判定时，记录缺失，该条结论保留当前级别。已有错误判定仍须保留。

`[agent] source_to_kernel` 独立开启。`stage_tool_source` 按本会话的证据别名把已保存的文本写入项目文件。`python_execute` 需显式声明该路径，读前核对本会话的暂存事件和哈希。研究包使用同一份内容对象。文件中的文本仍是不可信数据。

`[agent] vision` 与具体模型的 `vision` 声明同时开启，才为该模型附上本轮工具产生的最近两张 PNG 或 JPEG，每张至多 2 MiB。模型路由先判断项目分级；不支持图片的后备模型仍接收文本引用。事件与模型重放文件保存规范引用，传输时才读取图像字节。
