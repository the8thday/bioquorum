# ADR-031 研究线：比会话活得更久的结论、材料和决定

状态：已接受（2026-11-20）。补充 ADR-002、010、014、015、023。

## 背景
现在最大的工作单位是会话。真实的研发工作持续数周到数月：实验数据陆续回来，供应商会更正交付物，结论被新材料推翻，工作会换人接手。讨论里的检验场景是：周五收到一份更正表，研究者要知道周四的结论还成立吗、哪些图和材料受影响。通用 Agent 加 Skill 做不了这件事，因为它需要跨会话的版本和依赖记录。

## 决定
- 在项目之下、会话之上增加**研究线**（代码里叫 `program`）：一个持续的研究问题，包含若干会话、一组当前有效的结论、登记的材料和决定记录。一个项目可以有多条研究线；不属于任何研究线的会话照常工作。
- **材料登记**：外部文件（实验数据、供应商交付、文献 PDF）登记时进 CAS，记录来源说明、登记人和时间。同一份材料的新版本登记为"取代旧版本"，旧版本保留。
- **依赖从已有记录推出**：结论 → 绑定的值和引用 → run → 输入文件哈希 → 材料版本。不另建一套手工维护的依赖表。
- **失效传播**：材料被取代或撤回时，依赖它的 run、图和结论标记为"待复核"，并列出影响范围。【承重】"待复核"是叠加在可信度等级上的标记，不改写历史上的等级事件；复核通过重跑完成，重跑结果按 ADR-015 的规则重新挣得等级。原结论和更正后的结论都保留，可并排比较。
- **决定记录**：研究者写下"基于哪些结论，决定做什么"。决定引用结论的固定版本；所引结论进入"待复核"时，决定旁边显示提示。系统不替人做决定。
- **接手摘要**：从事件生成，列出问题、当前结论及等级、待复核项、未覆盖项（ADR-030）和决定。摘要是导航，不是证据。
- 所有状态走事件（ADR-002），研究线层面的事件用项目级事件流。研究包可以按研究线导出。

## 后果
- 新增一组事件类型和投影（实现时加入 ARCHITECTURE §5.3）；信息架构变为 项目 → 研究线 → 会话。
- 重跑受影响的分析要花模型和计算费用：先显示影响范围和费用估计，由研究者启动。
- 项目笔记（ADR-023）继续存在，用于约定和背景；研究线里的结论不能用笔记充当证据。
