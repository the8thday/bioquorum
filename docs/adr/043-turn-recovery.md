# ADR-043 · 从事件恢复中断的研究轮次

## 背景

关闭浏览器会断开 SSE。服务进程退出还会丢失内存中的模型请求、内核变量和权限等待对象。数据库与外部工具之间没有共同事务，进程可能在工具完成后、结果写入前退出。

## 决定

- 服务托管研究任务。启动时为悬空调用记录终止事件，保留已经提交的结果和批准的计划。
- 研究者可继续本会话最后一个中断轮次。将原轮次 ID 和已经人工核对的调用 ID 写入 `turn_resumed`。从原问题、引用、模型选择、已批准的计划和用量重建上下文。已有最终回答时接续审查，已完成的审查也可复用。
- 已经进入工具执行且结果不明的调用，恢复前要求研究者核对。相同工具和已记录参数在续跑期间跳过。外部操作的实际状态仍由该外部系统决定。
- 任务与待办从项目的事件读取。浏览器通知默认关闭，只在工作台打开且研究者已同意通知时提示有新事项。

## 后果

过程与科研证据可追溯。保存的文件、摘录和数值可跨服务进程使用；原内核里的临时变量可能丢失。继续执行时按当前项目权限和数据分级检查工具与模型。
