# ADR-026 私有部署的出站、隔离和审计边界

状态：已接受。延续 ADR-007、016、017。

工作台显示分级和从会话事件流推导的审计页。审计页只列调用、授权、运行和提供方元数据，采用只读分页接口。公开工作台仍仅绑定 loopback，远程单用户经 SSH 转发。

macOS 内核隔离由 `[kernel] macos_sandbox` 显式启用。使用系统的 `sandbox-exec`，默认拒绝文件和网络，仅许可项目、解释器、系统依赖和私有 Jupyter socket。配置与数据目录只读，会话状态目录不可读写。可用性探测失败时按 ADR-017 的分级规则处理。运行记录显示 `seatbelt`，复现升级仍根据已有独立环境条件判断。

外部 stdio MCP 可启用进程隔离，隔离模式为离线模式。进程无项目挂载，允许读取显式选定的运行时和资料。用户启动的 HTTPS 出站代理以精确主机和端口配置限制 CONNECT 路由，连接前只接受公开地址并直接连接已检查的 IP。只有连接到该代理的应用请求经过它，宿主机范围的封锁由部署网络完成。

容器镜像提供打包的 CLI 和运行时，同一主机的工作台可以经 SSH 安全访问。隔离能力按真实宿主机探测，容器内降级逻辑沿用 ADR-017。
