# ADR-038 · v0.8 新项目的推荐配置

已接受，2026-11-21。落实 ADR-032。

六题独立复跑与原配置逐题命中相同的 14/16 项。结合 30 对基线和预算内各机制的同题消融，新项目启用证据绑定，绑定重试次数为零，其余可选研究机制按需开启。[配置依据与限制](../research/v08-profile.md)

项目创建事件保存当时的推荐开关快照。加载时先应用创建快照，再合并全局与项目 TOML，最后重放用户保存的设置。显式修改预设内的开关时显示自定义。项目的第一次设置编辑继续使用空的先前修订号。旧版创建事件没有推荐快照，保留原有配置。冻结评测自行提供各臂的配置。
