# ADR-019 运行预算、压缩与 CLI 流式进度

状态：已接受。补充 ADR-014、018。

## 决定

- token、美元和用时阈值独立配置，作用于一次 `bq run` 的探索阶段，包含压缩。启用任一预算时，省略 `--max-steps` 即按预算运行。显式步数上限可并用。关闭预算时仍用原先的默认步数。
- 已完成请求按供应商实报用量累计。美元预算要求允许路由均配置价格，真实账单可能包含失败请求、缓存和供应商计费差异。用时按单调时钟在请求和工具边界检查。达到阈值后拒绝剩余工具请求，并允许一次无工具的收尾回答。最后的审查单独执行和计量；这些是探索阈值，单次请求、收尾及审查会增加总花费和用时。
- 探索停止原因记入 exploration_stopped 事件，收尾调用引用该事件。
- 压缩保留原始事件。只替换已经结束的消息前缀，保留最近的问题和完整的工具交互。摘要按不可信内容传给模型，证据索引始终以原始事件为准。压缩收益用开关对照测量。
- 流式模式把供应商增量用于终端的即时生成进度。证据解析后的正文在完整回答落盘后呈现。增量和推理过程不写入事件。流式与压缩独立开启，默认值由评测决定。
