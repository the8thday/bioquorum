# ADR-032 推荐配置组合，以及与通用 Agent 的两天对照

状态：已接受（2026-11-20）。补充 ADR-018。

## 背景
ADR-018 要求每个机制带开关并用评测说话。执行的结果是：Skills、项目笔记、文献子任务、绑定退回、压缩、图片、工具结果进 kernel 全部默认关闭，新用户开箱得到的是最少的那一套；已有对照没有观察到 harness 带来一致的准确率增益，只观察到更多可追溯的结论。另外，产品值不值得专门来用，要和配置良好的通用 Agent 比，不能只和自己的裸跑比。

## 决定
- 维护一份**推荐配置组合**（`[profile] recommended`）：把在留出题上有可测收益、费用可接受的机制一起打开。新建项目默认使用它；每个开关仍可单独关。组合的每次变动附评测对比，写进 `docs/research/`。
- 另有 `minimal` 组合（只有 kernel 工具和最短提示），用于消融和排查。
- **两天对照**是 v1.0 的发布门槛：同一个模型、同一批可用来源、同一项研究任务，BioQuorum 对比配置良好的通用 Agent。
  - 第一天：找到关键证据的比例（按预先写好的评分标准）、结论边界是否正确、费用和耗时。
  - 第二天：换一位没参与的人接手，再更正一份上游材料；测他弄清原结论、找全受影响之处、得到修订结果所需的时间和遗漏数。
- 任务和评分标准在运行前冻结；结果如实公布，包括输的项目。对外只引用这份对照里的数字。
- 第二天需要人参与，由作者或作者找的同行执行；AI 准备任务、材料和记录表。

## 后果
- 对照结果不好时，改的是产品，不是对照的口径。
- 第一天的对照在覆盖台账（ADR-030）之后做，第二天在研究线（ADR-031）之后做。
