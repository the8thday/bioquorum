# ADR-033 · 工作台上传与离线示例

状态：已接受。落实 ADR-006、016 与 029。

## 背景

浏览器需要把用户选定的文件交给本地 kernel，并在追问、下载或重跑时找回那一版字节。初次启动的项目也需要能演示一条完整记录。

## 决定

- 用户上传走独立的文件工具；文件内容流入 CAS，工具日志只记录登记所需的元数据。项目分级限制上传，生成的项目相对路径供 kernel 使用。每次上传有自己的 ID，重复文件名按事件顺序列出版本。
- 本轮附件随请求记录；模型收到本轮文件的相对路径和哈希，声明 kernel 输入时重新核对。展示运算结果继续使用已有的绑定和审查规则。
- 从真实项目进入 metformin 回放时，为示例单独建立工作区、事件库与会话。回放只使用随包录制的响应。

## 后果

关闭浏览器或重建投影后仍能从事件恢复附件归属。CAS 保存原始字节，用户可另行下载；项目内供 kernel 读取的副本发生变化时，声明为上传输入的验证会失败。示例操作不会混入真实项目的记录。
