# v0.4 暂缓的三项验收

v0.4 保留为候选版，v0.5 可以先开发。以下三项的验收结论不能由 v0.5 进展代替。

| 待验收 | 已经验证 | 还需跑通 | 完成证据 |
| --- | --- | --- | --- |
| Linux 端到端复现和独立重复 | Mac 真 Jupyter 重跑和浏览器比对；离线测试覆盖等级升级、输入隔离和盲消息。OrbStack Ubuntu 用户命名空间探测成功。 | 在 Ubuntu 预配 pixi、bubblewrap 和锁定的 Jupyter 依赖，再用真实隔离内核跑「已审查 → 已复现 → 已独立重复」。 | 同一结论的事件链、环境锁摘要、无网络隔离标记、盲输入记录、预登记容差及实际比对结果。 |
| 第二台机器重跑研究包 | 原机另一目录的独立脚本重跑成功；OrbStack Ubuntu 只执行过哈希校验。 | 在独立机器或独立计算环境按包说明重建环境并跑 `rerun.sh`。OrbStack 的跨系统实跑可作为前置检查。 | 保存另一环境的日志，记录锁文件、输入哈希和比较结果。 |
| 公开基准实跑 | 已从官方版本读取 BixBench v1.5 与 LAB-Bench TableQA v1 的固定四题子集，保存输入版本和哈希；评分入口可用。 | 准备对应数据包和表格，按冻结题目与评分规则实跑，保存模型配置、答案、失败和费用。 | 发布严格分母、模型得分及适用范围；把数据缺失和模型答错分开。 |

Linux 环境与执行步骤见 [v0.4 演示](../demo-v0.4.md)，公开基准口径见
[评测报告](../research/v04-verification.md)。项目约定由作者安装依赖，后续技术验收可由
