# v0.4 暂缓的三项验收

v0.4 保留为候选版，v0.5 可以先开发。以下三项的验收结论不能由 v0.5 进展代替。
2026-11-20 在 Ubuntu 24.04 服务器（bubblewrap 0.9、pixi 0.84.2）上执行，结果如下。

| 待验收 | 结果 | 证据 | 仍未覆盖 |
| --- | --- | --- | --- |
| Linux 端到端复现和独立重复 | 通过 | 同一结论的事件链为 `unverified → grounded → reviewed → reproduced → replicated`。所有 run 的 `isolation = bwrap`，锁摘要一致（`2dc6b07c…`）。盲重复只收到中性问题、定义和只读输入 `inputs/counts.csv`（sha256 `bb6d4bca…`），预登记容差为 0。GPT-6.1-sol 独立算出 68，与原值匹配。 | 演示用的是合成计数表，只验证流程，不代表科学分析。 |
| 第二台机器重跑研究包 | 部分通过 | 导出的研究包在另一个目录用 `sh rerun.sh` 从锁文件重建 pixi 环境：哈希校验通过，4 个 run 的输出和环境全部匹配。又在不含 BioQuorum、API key 和宿主缓存的 Debian 12 容器（`python:3.12-slim-bookworm`）里重跑，结果相同。 | 独立的物理机器和跨操作系统的研究包（例如在 Mac 上导出、到 Linux 重跑）还没测。 |
| 公开基准实跑 | 已执行，4/4 | 冻结的四题子集：BixBench v1.5 的 `bix-34-q5`、`q6`，LAB-Bench TableQA v1 两题。worker 为 GPT-6.1-sol。每题一个新的公开项目，只放该题的输入，kernel 在 bwrap 中运行。BixBench 用题目专属的锁定 pixi 环境（biopython、phykit 等）。没有失败，也没有缺数据。 | 只有四题，不能当作基准成绩对外引用。 |

## 实跑中发现并修复的问题

- 第一次盲重复的结果是「未能判定」：模型写了 `import bq`，kernel 里报 `ModuleNotFoundError`。
  现在 `import bq` 返回已注入的对象，盲重复提示也说明了 `bq` 已预先定义。
- 盲重复的 run 没有记录环境锁摘要。现在会记录。
- 示例环境里没有 pandas。模型先 `import pandas` 失败，这个失败的单元按规则使整条 kernel
  链不能用于重复（这条规则是有意保守的，没有放宽）。`examples/v04/pixi.toml` 已加上 pandas。

## 公开基准口径

| 题目 | 题型 | 模型答案 | 判定 | 工具调用 | 输入/输出 token |
| --- | --- | --- | --- | ---: | ---: |
| bix-34-q5 | 开放数值，绝对容差 0.005 | 1.95 | 对 | 3 | 8671 / 516 |
| bix-34-q6 | 开放数值，绝对容差 0.005 | 0.91 | 对 | 3 | 8922 / 560 |
| TableQA 75147404 | 选择题（5 个选项） | It increases from 43% to 91% | 对 | 1 | 7447 / 103 |
| TableQA 30d26305 | 选择题（6 个选项） | 72 h | 对 | 1 | 7345 / 62 |

- BixBench 两题都由模型自己从数据包里读出 IQ-TREE 树文件（动物 100 棵、真菌 249 棵），
  用 Bio.Phylo 算出每棵树的平均成对 patristic 距离，再用 `bq.value` 声明结果。答案里的数字是从记录的值填进去的。
- TableQA 按上游的选择题形式出题：标准答案和干扰项按题目 ID 的哈希固定排序，最后加上上游的
  "Insufficient information" 选项。原适配器只给题干、要求逐字写出标准答案，已改正。
- 评分用 `evals/v04_public_subset.py`，与执行脚本 `evals/v04_public_run.py` 分开。上游数据的 sha256 记在生成的 questions 文件里。
- 原始记录在本地 `evals/results/v04/`（不进仓库）。

Linux 环境与执行步骤见 [v0.4 演示](../demo-v0.4.md)，公开基准口径见
[评测报告](../research/v04-verification.md)。完整录屏、作者科学与布局验收以及发布仍按原路线图执行。
