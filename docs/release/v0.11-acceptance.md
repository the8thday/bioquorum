# v0.11 查看器与领域工具工程验收

2026-11-21 在基于 v0.9 的独立工作区验收 0.11.1–0.11.7。运行这些功能只需要既有的会话、产物、CAS 和工具权限机制。[操作演示](../demo-v0.11.md) · [架构决定](../adr/042-artifact-viewers.md)

| 步骤 | 实测 |
|---|---|
| 0.11.1 查看器 | 前端按产物类型懒加载，本地静态包包含渲染代码与许可。未知后缀会显示原文件下载。选区关联原始产物，浏览器刷新后可从研究轮次重开。报告支持引用原文行段。 |
| 0.11.2 表格 | 单元测试检查百万行数值排序与稳定的原始行号。本机对百万行 CSV 的一次 HTTP 接口测试同时请求降序和列统计，返回 30 行，响应正文 700 字节，耗时 2.67 秒。该数字是一次本机测量。浏览器流程在排序后引用了原文件第二行的单元格。 |
| 0.11.3 图 | 浏览器从合成计数图拖框选中样本 b，固定响应的测试工作线程读取引用，并经工具让真实 Python 内核重算。剩余计数为 3，新图与原图自动并排。同次运行的样本映射带哈希。Python 与 R 的映射辅助函数均实测。 |
| 0.11.4 结构 | 本地 Mol* 渲染 PDB 与 mmCIF。浏览器选择、引用并重开 PDB 的 H 链 Tyr52A；另用作者链 H、标准链 LA、模型号 7 的 mmCIF 检查链引用。结构选区来自 Mol* 解析的首个坐标模型，内容哈希固定原文件。引用本身只标记位置；距离等数值需通过计算取得。 |
| 0.11.5 序列 | 浏览器从 FASTA 选取第 2–3 位，也从真实内核生成的同次运行注释轨道点选区间。服务端按原始记录还原序列片段。 |
| 0.11.6 小分子和基因组 | RDKit.js 在专用本地 Worker 里把 SDF 记录渲染为 2D 图；igv.js 显示本地 BED 轨道，引用保留 0 起始的半开区间。轨道边界来自该 BED 的最大终点，参考基因组与组装未知。查看器浏览器流程观察到的外部 HTTP 请求数为 0。 |
| 0.11.7 领域 Skills | 四个包各 3 道留出题、每题开关各一次。两组各 12/12，两组之间的正确数差为 0。36 次 OpenAI 生成请求，共形成 24 份最终回答。项目按费率结算 0.041150 美元，授权上限 2 美元。继续默认关闭。[逐项评分和范围](../research/v11-domain-skills.md) |

0.11.8 已在 2026-11-22 接入完成的 v0.10。作者选定公开示例 1N8Z，工程验收已完成。作者于 2026-11-22 确认该示例的科学验收通过。[场景记录](../research/v11-scenarios.md)

## 回归与发行检查

在 0.10 完成提交上重新构建后，默认后端测试 568 项通过，34 项按标记排除；前端 20 项测试通过。另运行了研究线更正（场景 D）、查看器和真实 1N8Z 数据的浏览器流程。

前一日独立工作区的默认后端测试 534 项通过、32 项按标记排除，9 条导入契约、Ruff 检查和格式、Pyright 均通过。真实 R 内核的 wire 集成测试另行运行并通过。前端 15 项组件测试、TypeScript 生产构建和浏览器查看器流程通过。原有工作台、上传重算、引用回放浏览器流程也已通过。

将前端重新构建到空目录后，与随包静态文件逐字节一致。离线构建 wheel 和 sdist 均成功，已核对两种归档包含 Worker、WebAssembly、查看器许可与四个领域包。该开发分支沿用现有 Python 包版本号。

## 验收范围

- FASTA、MOL/SDF、BED 的预览上限各为 4 MiB，注释伴随文件上限为 2 MiB，图引用每次最多 64 个点。大表格独立走服务端分页和磁盘排序。
- Mol* 模块约 2.83 MB，gzip 约 793 kB，打开结构时加载。查看器随 wheel 分发；升级依赖后可用同一浏览器流程复查原版本引用。化学绘图另有独立的 WebAssembly 文件。[依赖与许可](../../THIRD_PARTY.md)
- 浏览器中的重算验证了选区传递、真实内核执行和新图回显。真实 OpenAI 测试覆盖四个领域包的选择题，复杂开放研究任务的质量仍待评估。
