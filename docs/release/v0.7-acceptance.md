## 首次观感验收后的修订

作者反馈 Usage 挤成碎字、会话操作过多、缺少项目创建入口。现已在左栏提供项目创建和切换，会话操作集中到标题旁的菜单。侧栏用量按指标纵向排列，按角色展开，窄屏实际检查了数字内部是否换行。用原会话副本复核了 14,472 输入 token、13,789 缓存读取和 34.97 s。浏览器测试实际创建独立项目、建立会话并切回，后端另验证关闭工作台后能重新打开。

新一轮验收覆盖跨格式选区引用、输入框快捷设置、跨项目和端口的全局偏好，以及已知与未知模型窗口的显示。Usage 的缓存指标单列。

公开练习项目的实时工具通过正常调用入口查询到 IL11 的 Ensembl 标识 ENSG00000095752，PubMed 返回论文编号并读到 PMID 31554736 的摘要。浏览器另验了运行与等待授权时的不同状态、跨格式选择原句并填写追问、保留原草稿、独立发送引用追问，以及从输入框选择附件后关联真实计算。

新增浏览器验收从 Home 发起研究，导入 Skill，再让测试 worker 经 open_skill 读取刚安装的正文；经侧栏注册、停用并移除 MCP，刷新后检查状态。在临时公开项目中也实测了通过扩展管理注册 PubMed 后的 MCP 工具发现。

已验证桌面拖动与键盘调宽、折叠导航、从已收起的右栏打开图，以及真实 Python kernel 写出的 CSV、SVG 与含图报告。右侧阅读区跨结果切换后保留左侧追问草稿。
