# v0.6 私有部署开发验收

| 项目 | 本机结果 | 待核对范围 |
|---|---|---|
| 分级与工作台审计 | 浏览器回归通过。会话范围、分页和原始参数排除已测试。 | 作者界面验收。 |
| macOS 内核隔离 | 真实 confidential Jupyter 会话通过私有 IPC。项目外文件、会话状态、配置写入与 IP 联网被拒绝，项目输出可写。 | 其它 macOS 版本。 |
| 离线 stdio MCP | 本机启动真实 SDK stdio 服务，正常工具调用，项目文件读取被拒绝。 | Linux 上真实隔离 MCP 进程。 |
| HTTPS 出站代理 | 允许路径的本地隧道、拒绝域名与拒绝非公开地址通过。Mac 和本机 Linux VM 都把实测外部域名解析到非公开地址，实测对这些连接返回拒绝。 | 在返回公开地址的部署网络测试实际 HTTPS 往返。 |
| 开发分发包 | 已从源码离线生成 `0.6.0.dev0` wheel 和 sdist，解包后检查 CLI 与工作台资源。开发包重建后逐成员检查源码范围、缓存和构建机路径；发布工作流使用同一检查。 | 正式发布由作者决定。 |
| Docker | 已提供非 root CLI 镜像定义及使用说明。 | 本机 Docker 未缓存所需 Python 基础镜像。需要有基础镜像和系统依赖的环境跑构建及 Linux smoke。 |
| 服务器和本机模型 | 已记录 SSH loopback 访问、模型端点、离线 MCP 和 HTTPS 出站配置。 | 指定部署主机后的端到端演练。 |
