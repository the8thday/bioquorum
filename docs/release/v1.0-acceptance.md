## 同一份研究包的跨系统重跑

目的为区分传输、环境和重算输出的差异。使用已有公开 GSE96583 包、包内原始代码及输入。2026-11-22 在 macOS ARM64 分别解包到新目录，先运行 `sh rerun.sh --verify-only`，再用本机已按同一把锁配置的 `examples/v09/.pixi/envs/default/bin/python` 执行各自包内的 `run.py`。两个包的锁均与本机锁逐字节匹配。重跑没有调用模型或安装依赖。

| 导出 → 重跑 | 文件校验 | 重算结果 |
|---|---|---|
| macOS ARM64 → macOS ARM64，本轮阳性对照 | 通过 | 退出 0。Python 与 R 两个单元的 `outputs_matched` 和 `environment_matched` 全部为 true。 |
| Linux ARM64 → macOS ARM64，本轮 | 通过 | 退出 1。R 单元生成的 `outputs/v09/deseq2-results.csv` 哈希与原记录不同。 |
| macOS ARM64 → Linux ARM64，v0.9 已执行 | 通过 | 在同一 CSV 的严格校验处失败。 |
| Linux ARM64 → 断网 Linux ARM64 容器，v0.9 已执行 | 通过 | 两个单元的输出与环境均匹配。[原始验收记录](v0.9-acceptance.md) |

本轮又从两份原包的 manifest 定位 CSV，并按对象哈希校验后按唯一基因 ID 对齐。两边都有 5,140 个基因，BH 调整后 p 值 ≤ 0.05 的基因各有 2,896 个，逐基因阈值分歧为 0。只有 2 行的所有 CSV 字段文本完全相同。这个比较限定于这份数据和这个阈值；严格重跑保留失败结果，可信度等级保持原判。[验证规则](../adr/022-verification-and-portable-record.md)
