## 跨平台边界

macOS 包在独立 macOS 锁定环境重跑一致。直接把该包在 Linux 重跑，完整精度的差异分析 CSV 哈希不同，严格重跑报告失败。两个平台的 5,140 个基因中，FDR 阈值判定全部一致。同平台 Linux 独立容器验收使用重新采集的 Linux 原始会话。两个平台的数据和包分别保留。
