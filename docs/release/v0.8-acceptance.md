## 本机验证

最终配置通过 512 项后端测试（默认排除 29 项）、9 条分层契约、Ruff、Pyright、14 项前端测试及 10 条浏览器流程。干净目录中的前端构建与随包资源逐字节一致。通过 CLI 创建并重开项目，再通过浏览器验证工作台新项目的推荐配置、保存最小配置、刷新、切回推荐、手动开启引用后显示自定义。旧版创建事件和项目 TOML 覆盖另有回归测试。

### 此前的阶段性验证

加入会话并发调度后，后端测试 489 项通过，29 项按默认标记排除。9 条分层契约、Ruff、Pyright 通过。前端 12 项组件测试和生产构建通过。10 条浏览器流程通过，包含覆盖台账展开、分歧或下一步的原句进入草稿、发送与刷新，以及原有的会话、项目、扩展、布局、首次使用、上传、引用和项目笔记流程。核对构建后的 wheel，其中有三份内置 SKILL.md。模型调用的离线测试使用模拟 HTTP 响应，付费验收另列在基线报告。

另用模拟 Responses 服务和四个真实隔离 Python 内核同时执行四个组学会话，每个会话分别读随题 CSV 并独立完成研究、审查和评分。观察到四笔模型请求同时在途，逐会话的费用预留之和与共享测试账本一致。正式 OpenAI 的加速倍数取决于实际限流和任务分布。
